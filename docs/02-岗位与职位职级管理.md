# 岗位与职级管理

## 1. 功能定位

岗位管理用于维护部门下的岗位设置、岗位职责、任职要求和编制信息。

职级管理用于维护全局统一的岗位层级标准。职位与职级在本系统中表达同一概念，统一称为「职级」，不再通过类型区分。

岗位归属于部门，职级标准项全局维护。岗位与职级相互独立，不建立绑定关系；人员任职时分别选择岗位和职级。

## 2. 岗位与职级关系

```text
部门 -> 岗位
人员任职 -> 部门 + 岗位 + 职级标准项
```

示例：

| 人员 | 部门 | 岗位 | 职级 |
|---|---|---|---|
| 张三 | 研发部 | 前端工程师 | 高级专员 |
| 李四 | 研发部 | 前端工程师 | 专员 |
| 王五 | 财务部 | 会计 | 专员 |

规则：

- 岗位由部门自行维护。
- 岗位数量通过编制表达。
- 同一部门下岗位编码必须唯一。
- 同一部门下岗位名称建议唯一。
- 岗位不设置职级，同一岗位下的不同人员可以拥有不同职级。
- 人员任职时独立选择职级，更换部门或岗位不会自动修改职级。

## 3. 岗位管理页面

### 3.1 页面布局

采用按部门组织的树形表格，与菜单管理的树表交互保持一致，不使用分页。

- 树节点只表示部门，子部门按组织层级继续嵌套。
- 「岗位」作为一级分组表头，二级表头依次为名称、编码、正式、外包、兼职、在岗、超编、状态和操作。
- 岗位通过各二级列的单元格插槽嵌入直属岗位列表，不作为树节点；同一岗位在各二级列中占据相同顺序、相同高度的子行。
- 一个部门只有一条外层表格行；该部门有几个直属岗位，岗位单元格内就纵向生成几条子行。
- 岗位子行之间使用普通分隔线，不使用跨行或合并单元格。
- 默认展开全部节点，用户可逐级收起或展开。
- 部门行汇总本部门及全部下级部门岗位的编制、在岗、空缺和超编数据。
- 部门行提供「新增岗位」，打开新增抽屉并默认选中当前部门；停用部门不可新增岗位。
- 每条岗位子行展示岗位名称、编码、正式编制、外包编制、兼职编制、在岗人数和超编人数，并保留详情、编辑和启用 / 停用操作。
- 正式、外包、兼职、在岗和超编列的数字均可点击；点击后使用弹窗展示该岗位对应口径的人员列表，数字为 0 时也可打开空列表。
- 人员列表口径：正式为有效主职且员工类型为正式，外包为有效主职且员工类型为外包，兼职为有效兼职任职，在岗为当前有效且占用编制的任职；超编人员按占用编制人员的入岗日期倒序取超出总编制的数量。
- 按岗位名称、岗位编码、状态或超编状态筛选时，只保留命中岗位及其完整部门祖先路径。
- 选择某个部门筛选时，展示该部门及其完整下级部门树。

筛选区：

- 所属部门
- 岗位名称
- 岗位编码
- 状态
- 是否超编

表格列：

- 部门
- 部门编码
- 上级部门
- 岗位（一级分组表头）
- 名称、编码、正式、外包、兼职、在岗、超编、状态、操作（岗位二级表头）
- 直属岗位数
- 状态
- 操作

操作：

- 新增岗位
- 编辑岗位
- 查看详情
- 启用
- 停用

导入、导出暂不实现，页面不展示对应入口。

## 4. 岗位字段

| 字段 | 是否必填 | 控件 | 说明 |
|---|---:|---|---|
| 岗位名称 | 是 | 输入框 | 如前端工程师、后端工程师 |
| 岗位编码 | 是 | 输入框 | 同一部门下唯一 |
| 所属部门 | 是 | 树选择 | 仅可选择启用部门 |
| 岗位类型 | 否 | 下拉选择 | 正式、外包、实习、管理等 |
| 正式编制 | 否 | 数字输入 | 正式人员编制数量 |
| 外包编制 | 否 | 数字输入 | 外包人员编制数量 |
| 兼职编制 | 否 | 数字输入 | 用于统计展示 |
| 岗位职责 | 否 | 多行文本 | 职责说明 |
| 任职要求 | 否 | 多行文本 | 任职要求 |
| 排序号 | 否 | 数字输入 | 展示排序 |
| 状态 | 是 | 单选/标签 | 启用 / 停用 |
| 岗位说明 | 否 | 多行文本 | 其他说明 |

## 5. 新增岗位

入口：点击「新增岗位」。

打开方式：右侧抽屉。

校验：

- 所属部门不能为空。
- 所属部门必须为启用状态。
- 岗位名称不能为空。
- 岗位编码不能为空。
- 岗位编码在同一部门下不可重复。
- 岗位名称在同一部门下重复时，提示但不强制阻止。

保存后：

- 岗位默认启用。
- 刷新列表。
- 可在岗位详情查看在岗人员和编制情况。

## 6. 编辑岗位

可编辑：

- 岗位名称
- 职级
- 岗位类型
- 岗位职责
- 任职要求
- 编制人数
- 排序号
- 岗位说明

规则：

- 岗位已有有效任职人员时，不建议修改所属部门。
- 如需变更岗位所属部门，应通过部门迁移或人员调岗处理。
- 修改编制后，需要重新计算空缺和超编。
- 岗位编码允许修改，修改时需要校验同部门唯一。
- 岗位没有有效任职时可直接修改所属部门；存在有效任职时锁定所属部门。

## 7. 岗位详情

打开方式：右侧详情抽屉。

详情不使用页签。基础信息、编制统计、在岗人员和历史任职在宽抽屉中直接平铺展示，信息优先横向展开。

### 7.1 在岗人员

列：

- 姓名
- 工号
- 任职类型
- 是否主岗位
- 入岗日期
- 是否占用编制
- 人员状态

### 7.2 编制统计

展示：

- 正式编制
- 外包编制
- 兼职编制
- 当前在岗人数
- 空缺人数
- 超编人数

## 8. 岗位编制

编制类型：

- 正式编制
- 外包编制
- 兼职编制

规则：

- 正式人员占用正式编制。
- 外包人员占用外包编制。
- 兼职人员不占用编制。
- 调岗后自动释放原岗位编制并占用新岗位编制。
- 离职后自动释放编制。
- 兼职结束后不涉及编制释放，因为兼职不占编制。
- 超编时仅提示，不禁止继续分配人员。
- 总编制为正式编制与外包编制之和。
- 当前在岗人数仅统计当前有效任职且占用编制的人数。
- 兼职编制仅用于统计展示，不参与空缺人数和超编人数计算。

展示指标：

| 指标 | 说明 |
|---|---|
| 编制人数 | 岗位配置的可用名额 |
| 当前在岗人数 | 当前有效任职且占用编制的人数 |
| 空缺人数 | 编制人数 - 当前在岗人数 |
| 超编人数 | 当前在岗人数 - 编制人数 |

超编提示：

```text
当前岗位已超出编制人数，系统仅做提示，不阻止继续分配人员。
```

## 9. 人员任职中的职级

- 人员任职分别选择部门、岗位和职级，三者不自动联动。
- 人员新增、任职编辑、调整主职、新增兼职和调整兼职均可独立选择职级。
- 更换部门或岗位时保留当前职级，只有用户主动选择时才修改。
- 人员任职界面不展示职位、岗位编码或职级编码。
- 当前有效任职展示所选职级名称；已结束的历史任职保留结束时的职级名称快照。
- 职级名称修改后同步更新当前有效任职，不改写历史任职。

## 10. 岗位停用

入口：点击「停用」。

规则：

- 岗位下存在有效任职人员时，不允许停用。
- 必须先调岗、离职或结束任职关系。
- 停用后岗位不可再被新增人员选择。
- 停用岗位仍可在历史任职记录中查看。

提示文案：

```text
该岗位下存在有效任职人员，请先调岗、离职或结束任职关系。
```

## 12. 职级字段

| 字段 | 是否必填 | 控件 | 说明 |
|---|---:|---|---|
| 名称 | 是 | 输入框 | 职级标准项名称 |
| 编码 | 是 | 输入框 | 唯一编码 |
| 层级 | 是 | 数字输入 | 层级顺序 |
| 排序号 | 否 | 数字输入 | 展示排序 |
| 描述 | 否 | 多行文本 | 说明 |
| 状态 | 是 | 单选/标签 | 启用 / 停用 |

## 13. 职级规则

- 编码必须唯一。
- 编码允许修改，修改时重新校验全局唯一。
- 停用后不可被新任职选择。
- 已被有效任职引用时，停用前需提示影响范围，用户确认后可停用。
- 启用中的职级标准项不可删除；停用且无有效任职引用时，二次确认后可删除。
- 停用但仍被当前有效任职引用的标准项继续展示，但不可被其他任职新选中。
- 历史任职记录保留原职级名称。

## 14. 部门合并中的新建岗位

部门合并选择「新建目标岗位」时，表单与正常新增岗位字段完全对齐：岗位名称、岗位编码、岗位类型、正式编制、外包编制、兼职编制、岗位职责、任职要求、排序号和岗位说明。

- 默认带入源岗位的完整配置，用户可在合并方案中逐项修改。
- 目标部门由合并流程确定，表单内不重复选择部门。
- 岗位编码按目标部门校验唯一。
- 所有岗位映射完成后才可进入后续步骤。
